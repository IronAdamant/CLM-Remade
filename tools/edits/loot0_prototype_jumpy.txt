# Loot mode, prototype (2026-10-10): tests the two core mechanisms on one family before generating the rest.
#  1. Unlock holotape: a BOOK with "Add Perk" (how vanilla magazines work - no script, so PlayStation-safe).
#     Picking it up grants a hidden perk; recipes that check that perk then appear.
#  2. Loose mod: a MISC item linked from the legendary's LNAM, like vanilla loose mods. Holding it should let the
#     legendary be attached at a workbench, consuming the item. Vanilla legendaries never have one, hence the test.
